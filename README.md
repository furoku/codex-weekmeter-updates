# Codex Weekmeter Updates

This public repository contains only compiled update artifacts and the Sparkle update feed for Codex Weekmeter.

Published content is limited to:

- `appcast.xml`
- versioned release notes
- signed, compiled macOS application archives attached to GitHub Releases

The Codex Weekmeter source repository remains private. No source code, Git history from the source project, credentials, signing keys, Codex usage data, or personal settings are published here.

Update archives are verified with a Sparkle EdDSA signature. Current builds use a local macOS code signature and are not notarized with an Apple Developer ID.
